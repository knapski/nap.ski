# NAP Consulting — nap.ski

Premium static mockup homepage for **NAP Consulting** (medical device / management consulting). Under-construction aesthetic with live contact via nap@nap.ski.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4

## Setup

```
cd site
npm install
```

## Develop

```
npm run dev
```

Opens a local dev server (typically http://localhost:5173).

## Build

```
npm run build
```

Output lands in dist/.

## Preview production build

```
npm run preview
```

Serves the built site locally (typically http://localhost:4173).
